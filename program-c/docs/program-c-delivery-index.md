## Verification Commands

Run from `program-c/`:

```bash
npm run check
```

This expands to:

```bash
npm run typecheck
npm run validate:content
npm run validate:integration
npm run build
npm run verify:offline
npm run report:size
npm run report:gzip
npm run report:week1
```

Run from repo root for the integrated app:

```bash
npm run typecheck
npm run smoke:integration
npm run smoke:week1
npm run build
```
