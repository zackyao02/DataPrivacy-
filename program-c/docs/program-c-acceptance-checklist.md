# 程序C验收清单

本清单用于说明“程序C：内容工具与音效 / 构建与性能”当前完成度，不覆盖其他同学负责的主流程、视觉、存档、结局和分享页。

## 已完成

- 内容数据首批最小闭环：卡牌、用户、买家、变量池、新闻、协议词、打包配方。
- 内容工具：`ContentRepository` 支持读取卡牌、用户、买家、新闻、协议词、打包配方。
- 打包辅助：可根据卡牌 ID 生成打包预览，返回是否可打包、缺失数据类型、匹配买家和关联新闻。
- Day 2 内容：`day_challenges.json` 已覆盖 Day 1「协议伪装」和 Day 2「数据清洗」。
- 小关卡读取：`findChallengeByDay(2)` 可返回数据清洗目标、干扰项、倒计时、成功条件和徽章。
- 变量替换：支持 `{姓名}`、`{城市}`、`{金额}`、`{平台}`，可优先使用当前用户的姓名和城市。
- 音效系统：`AudioManager` 支持按游戏事件名触发 Web Audio 程序化音效。
- 音效事件名：已覆盖卡牌生成、入槽、打包、废包、交易、风险、新闻、情绪、清醒值、结局。
- 内容校验：检查 ID 重复、数据类型、敏感度、包类型引用、占位符、配方可组装性、小关卡引用、新闻三情绪反馈。
- 构建清单：生成 `dist/content-manifest.json`。
- 离线清单：生成 `dist/offline-assets.json`。
- 离线就绪检查：确认程序C资源不依赖外部 URL。
- 包体检查：raw 和 gzip 均低于 8MB。
